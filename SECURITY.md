# Безопасность Ноты 59

## Текущее состояние

В боте есть фильтр ссылок, /report с лимитом, /warn, /ban, контроль прав бота и постоянный SQLite-журнал. Автоматические муты и баны выключены. /warn только предупреждает и записывает событие; /ban по-прежнему требует ручного подтверждения администратора.

Журнал хранится в security_log.db рядом с main.py. Путь можно изменить переменной SECURITY_DB_PATH. Файл базы не должен попадать в GitHub: он уже указан в .gitignore.

## Настройки GitHub

Проверь в Settings репозитория:

1. Settings / Code security and analysis: включи Dependabot alerts, Dependabot security updates, Secret scanning и Push protection.
2. Settings / Secrets and variables / Actions: убедись, что BOT_TOKEN не добавлен как обычный secret или переменную; токен должен быть только на BotHost.
3. Settings / Branches: при желании включи защиту ветки main, чтобы изменения проходили через pull request и обязательную проверку тестов.
4. Actions: проверь, что последний запуск Bot regression tests зелёный.

## Команды

- /report — ответить на подозрительное сообщение; максимум 3 жалобы за 10 минут от одного участника.
- /warn — ответить на сообщение участника; доступно владельцу и администраторам с правом блокировки; максимум 5 за минуту.
- /ban — блокировка; доступна владельцу и администраторам с правом блокировки; максимум 3 за минуту.
- /security — диагностика прав и фильтра в личном чате владельца.
- /security_ids — ID чата, владельца и настроенной группы.

## Журнал

В security_log.db записываются жалобы, удаления ссылок, предупреждения, баны, изменения прав бота и статус защиты. Это помогает восстановить историю после перезапуска. Не публикуй базу, логи или ID участников в Issues.

## Ограничения

Кнопка «Пожаловаться» не может быть добавлена к чужим сообщениям: Telegram этого не позволяет. Она есть в сообщениях /rules и приветствиях. QR-коды, ссылки внутри изображений и личная переписка мошенников с покупателями не контролируются.

При утечке BOT_TOKEN отзови его через BotFather, создай новый и обнови секрет на BotHost. Не храни токен в коде, переписке или GitHub.
